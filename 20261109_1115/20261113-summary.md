## 1. 課堂授課重點（授課教授講評）

### 1.1 量化研究嚴謹度：雙胞胎智力與遺傳控制
* **控制變數的重要性**：量化研究的核心在於嚴謹控制外生與混淆變數。以探討「智商是先天的遺傳還是後天的教養」為例，最嚴格的實驗控制就是觀察雙胞胎：
  * **同卵雙胞胎一起養育**：基因相同、環境相同，智力相關係數高達 0.94，能解釋 80% 以上的智力變異。
  * **同卵雙胞胎分開養育**：基因相同、環境不同，智力相關係數仍達 0.77。這證明智力主要由先天決定，但後天環境依然具備微幅影響力（若後天無影響應保持 0.94）。
  * **身高與體重**：分開養育的同卵雙胞胎相關係數高達 0.95，顯示身體特徵主要由先天主導，後天能改變的幅度僅約 2-3%。
  * **異卵雙胞胎與無血緣同住**：無血緣孩子同住的智力相關係數約為 0.24，再次佐證共同環境對智力存在一定程度的塑造作用。

### 1.2 頂尖期刊量化範式：新產品開發時間縮短研究 (*ASQ* 案例)
* **直覺 vs. 實證嚴謹度**：發表於頂尖管理期刊 *Administrative Science Quarterly (ASQ)* 的經典文章，探討「如何縮短企業新產品開發 (NPD) 時間」，展示了將實務直覺轉化為量化變數的模型設計：
  * **正向加速因子**：
    * **規劃時間長度**：事前規劃越完整、審慎，後續重工越少，開發速度越快。
    * **供應商深度參與**：避免後期備料與技術斷鏈。
    * **電腦輔助設計 (CAD) 應用多寡**：提高設計與修改效率。
    * **專案重疊與借鑑程度**：模組重複利用率越高，開發時程越短。
    * **多功能團隊 (Cross-Functional Team) 實質參與**：跨部門（軟體、硬體、Sales）及早介入發現防範問題。
    * **時程掌控獎勵機制**：提供按時交付的實質動機。
    * **測試的周延程度與及早測試**：早期單元測試 (Unit Test) 越周全，後期修補成本越低。
    * **專案領導人權力大小**：被授權度與調動資源能力越高，推進速度越快。
  * **負向（越短越好）因子**：
    * **重要檢核點 (Milestone) 間隔時間**：檢核點間隔越短，越能及早發現偏差並快速修正。
* **學術貢獻意涵**：實務經理人看似直覺的常理，透過嚴謹的變數測量與回歸分析予以驗證，即構成具備獲獎水準的頂尖學術貢獻。

### 1.3 多重驗證法 (Triangulation) 的四種層次與價值
研究過程常是孤獨的，研究者需要夥伴與跨角度的檢視。為克服單一方法的偏誤，現代頂尖研究高度強調「多重驗證（三角驗證法）」：
1. **方法的多重驗證 (Method Triangulation)**：
   * **質化與量化交互驗證**：初探階段研究者不清楚關鍵因子時，先以質化訪談領域專家找出核心變數，再發展量表進行大規模問卷量化檢定；或以量化發現的異常結果，透過深入訪談進行脈絡化詮釋。
2. **資料的多重驗證 (Data Triangulation)**：
   * 結合問卷調查、深度訪談、現場觀察錄影與公司財報次級資料等多元數據源。
3. **研究者的多重驗證 (Investigator Triangulation)**：
   * 常見於質化訪談編碼（如由 2-3 位研究者獨立編碼，再計算編碼一致性/信度），確保詮釋客觀性。
4. **理論的多重驗證 (Theory Triangulation)**：
   * 從多個不同學派的理論視角（如代理理論 vs. 利益關係人理論）對同一實證現象進行交叉詮釋。

### 1.4 量化思維在職場管理與論文中的定位
* 雖然 EMBA 論文撰寫多數偏好質化個案，但具備量化數據素養能大幅提升職場競爭力。
* 例如：企業 HR 招募時常進行智力測驗，若能累積數據並跑統計分析「智力分數與工作考核績效是否具顯著相關」，即可科學化評估是否保留該測驗，避免無效的人資作業成本。

## 2. 第三組論文導讀重點：《企業社會責任對於公司財務績效之影響：是雙面刃嗎？》

### 2.1 研究核心問題與對立理論假說
* **核心問題**：企業花費大筆預算投入公益、環保與員工照顧，到底是在為企業「累積市場價值」，還是純粹「增加公司負擔」？
* **兩大對立理論視角**：
  * **假說一：名利雙贏 (Doing Well by Doing Good) / 聲譽保險 (Reputation Insurance)**
    * 平時照顧員工、回饋社會可累積「道德資本 (Moral Capital)」與聲譽存款。
    * **短期保護**：遭遇負面盈餘消息時，外界傾向給予信任，股價相對抗跌。
    * **長期效益**：顧客願意支付道德溢價 (Price Premium)，增強經營績效。
  * **假說二：資源扭曲 (Resource Misallocation) / 代理成本 (Agency Cost)**
    * 經理人可能為了個人名聲與光環（如沽名釣譽、擴充個人人脈），將股東資源投入與本業無關的 CSR 項目，增加股東承擔的無效成本。

### 2.2 量化研究設計、變數操作與分析方法
* **自變數 (IV)**：是否入選「道瓊永續指數 (DJSI)」（虛擬變數：入選為 1，未入選為 0；*註：DJSI 於 2025/2/10 更名為 DJBIC*）。
* **應變數 (DV)**：
  * **短期市場績效**：負面盈餘宣告事件發生後 1-3 天的累積異常報酬率 (CAR)。
  * **長期營運績效**：資產報酬率 (ROA)、營業利益率、營業費用率、銷管費用率。
* **調節變數 (Moderator)**：代理成本 (Agency Cost)，檢驗公司治理好壞是否調節 CSR 的保護效益。
* **控制變數 (CV)**：公司規模、市值淨值比 (MTB)、產業別、年度等。
* **三大分析方法**：
  1. **事件研究法 (Event Study)**：捕捉短天期市場超額報酬波動。
  2. **多元回歸分析 (Multiple Regression)**：排除干擾因素，驗證長期財報關聯。
  3. **交乘項分析 (Interaction Analysis)**：檢驗 $CSR \times Agency\ Cost$ 的調節效應。

### 2.3 實證結果解讀與統計意涵
* **短期抗跌保護效果顯著**：
  * 遭遇負面盈餘公告時，入選 CSR 的企業其股價跌幅顯著較小（CAR 差異約 0.3% - 0.4%），回歸係數 $\beta = 0.535$ ($p < 0.001$，達三顆星顯著）。
  * 代理成本越高的公司，CSR 產生的抗跌交乘係數達 2.494 且顯著，支持 CSR 具備聲譽保險的防禦功能。
* **長期營運績效部分支持**：
  * 入選 CSR 之企業，平均 ROA 高出 1.1 個百分點，營業利益率高出 2.0 個百分點（14.6% vs. 12.6%）。
  * 追蹤 2-3 年時，部分年度回歸係數呈正向顯著，但樣本數隨著年限拉長而遞減。
* **判定係數 ($R^2$) 的實務解讀（教授特別補充）**：
  * 該篇得獎論文的模型 Adjusted $R^2$ 僅約 2% 至 3%。
  * 教授解釋：**使用次級資料（財報、股價）做實證，能解釋 10% 變異量就已經謝天謝地**。股價受宏觀景氣、產業變動與投資人非理性情緒影響極大。儘管 $R^2$ 較低，但係數達統計顯著性，代表 CSR 確實存在不可忽視的邊際影響。

### 2.4 研究限制與批判性省思
1. **樣本選擇偏誤**：樣本作集中於全球《財富》500 大跨國企業，難以直接外推至台灣企業或資源匱乏的中小企業。
2. **變數簡化失真**：將複雜的 ESG 實踐以 0/1 虛擬變數粗略二分，無法衡量投入強度與連續性。
3. **反向因果（內生性問題）**：到底是「做 CSR 讓企業獲利更好」，還是「原本就賺大錢的好公司才更有閒錢做 CSR」？難以完全排除充裕資源理論 (Slack Resource Theory) 的因果混淆。
4. **相關不等於因果**：統計顯著不保證投入 CSR 就一定能轉化為利潤，管理決策仍需評估核心業務契合度。

## 4. 助教統計實作教學重點：線性回歸、ANOVA 與多元回歸

### 4.1 變數類型與統計檢定方法對照矩陣
選擇統計方法必須依據「自變數 (IV)」與「應變數 (DV)」的尺度類型決定：
* **變數類型**：
  * **類別型 (Categorical)**：名目尺度（性別、宗教）、順序尺度（名次、年級）。
  * **連續型 (Continuous)**：區間尺度（溫度、智商、滿意度）、比例尺度（年齡、收入、長度，具備絕對零點）。
* **檢定方法選用對照**：
  1. **IV 類別 + DV 類別** $\rightarrow$ **卡方檢定 (Chi-Square Test)**（如：性別與購買商品類別關聯）。
  2. **IV 類別 (2組) + DV 連續** $\rightarrow$ **獨立樣本 t 檢定 (t-Test)**。
  3. **IV 類別 (3組以上) + DV 連續** $\rightarrow$ **單因子變異數分析 (One-Way ANOVA)**。
  4. **IV 連續 + DV 連續** $\rightarrow$ **相關分析 (Correlation) / 線性回歸 (Linear Regression)**。
  5. **IV 任意 (需虛擬編碼) + DV 連續** $\rightarrow$ **多元線性回歸 (Multiple Regression)**。
  6. **DV 類別 (二元 0/1)** $\rightarrow$ **羅吉斯回歸 (Logistic Regression)**（如：違約與否、放貸與否）。

---

### 4.2 簡單線性回歸實作（廣告費用 vs. 銷售額）
* **回歸公式**：$y = a + bx$
* **實作案例**：自變數 $x$ 為廣告費用（千元），應變數 $y$ 為銷售額（千元）。
* **重要指標解讀**：
  * **判定係數 ($R^2 = 0.908$)**：該模型能解釋銷售額 90.8% 的變異量，解釋力極高。
  * **截距/常數項 ($a = 8977.694$)**：當廣告費為 0 時，預期基準銷售額為 8,977.694 千元。
  * **斜率/係數 ($b = 5.754$)**：每投入 1 千元廣告費，銷售額預期增加 5.754 千元。
  * **標準化係數 ($\beta = 0.953$)**：消除單位維度影響，廣告費每增加 1 個標準差，銷售額增加 0.953 個標準差。
  * **顯著性 ($p < 0.001$)**：小於 0.05 門檻，係數顯著不為 0。
  * **95% 信賴區間 $[3.939, 7.580]$**：區間均為正數、**未包含 0**，確認影響為正向且穩定。

### 4.3 單因子變異數分析 (One-Way ANOVA) 與事後檢定（四種飲食減重法）
* **問題設定**：比較四種飲食法（地中海、生酮、減醣、168 斷食；各 25 人，共 100 筆資料）對三個月減重公斤數的差異。
* **變異數分解架構**：
  * **組間變異 (Between-group Variance)**：各組平均值與總平均值的差距（**希望越大越好**）。
  * **組內變異 (Within-group Variance)**：組內個別數值與該組平均值的差距（**希望越小越好**）。
  * **統計量**：$F = \frac{\text{組間均方 (MSB)}}{\text{組內均方 (MSW)}}$，本例 $p = 0.010 < 0.05$，代表四組平均值顯著不同。
* **事後多重比較 (Tukey's HSD Post-hoc Test)**：
  * ANOVA 僅能證明「組別間存在顯著差異」，無法指出「具體是哪兩組不同」，必須進行事後檢定。
  * **分析結果**：六組兩兩配對比較中，**僅「168 斷食法」與其他三組呈現顯著差異 ($p < 0.05$)**，其減重成效顯著優於其他三組；而地中海、生酮與減醣三者之間無顯著差異。

### 4.4 多元線性回歸實作與共線性診斷（學生生活習慣與考試成績）
* **資料與虛擬變數轉換 (Dummy Coding)**：
  * 將無順序或二元類別轉化為 0/1（如：打工 No=0, Yes=1；課外活動 No=0, Yes=1）。
  * 具層級次序變數轉化為數值等級（如：網路品質 差=1, 平=2, 好=3；父母學歷 高中=1, 學士=2, 碩士=3）。
* **多變數回歸結果評析**：
  * **不顯著因子 ($p > 0.05$)**：打工與否、參與課外活動與否，對考試成績無顯著影響。
  * **顯著因子 ($p < 0.05$)**：
    * 讀書時數：每多讀 1 小時，成績顯著提升 **+9.5 分**。
    * 睡眠時數：每多睡 1 小時，成績提升 **+2.0 分**。
    * 出席率、運動次數、心理健康度均具正向顯著影響。
    * 社群媒體時數 (-2.6 分) 與 Netflix 時數 (-2.2 分) 具負向顯著衝擊。
* **調整後判定係數 (Adjusted $R^2$) 的必要性**：
  * 傳統 $R^2$ 會隨著自變數個數增加而虛胖膨脹。自變數較多時，**必須以 Adjusted $R^2$ (本例為 0.90) 作為真實解釋力基準**。
* **共線性問題 (Multicollinearity) 與診斷標準**：
  * 若自變數間高度重疊（如同時放入「出席率」與「請假天數」），將導致回歸係數估計失真。
  * **檢驗指標**：
    1. **容差 (Tolerance)**：不得小於 0.1。
    2. **變異數膨脹因子 ($VIF = \frac{1}{\text{Tolerance}}$)**：**不得大於 10**（理想接近 1）。
  * 本例 VIF 均接近 1，無多元共線性疑慮。

### 4.5 AI 工具與統計分析軟體工具推薦
* **AI 輔助數據分析**：助教示範利用 Gemini 生成 Python Web App 進行回歸與變異數分析。一般簡易統計可直接將 Excel 上傳至 ChatGPT/Gemini 進行 Prompt 提示分析。
