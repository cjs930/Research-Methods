# 1151研究方法-朱宇倩 課程筆記與管理方法整合

## 一、 課程基本資訊
- **課程名稱**：國立臺灣科技大學管研所 EMBA研究方法[cite: 1]。
- **授課老師**：朱宇倩教授[cite: 1]。
- **課程目標**：協助學生釐清研究方向，建立正確的研究觀念，課程涵蓋系統性的研究方法、研究倫理、統計分析及個案寫作，最終引導學生完成好的論文[cite: 1, 2]。

## 二、 研究方法與程序 (Research Process)
根據「introduction RM_20260911.pptx」的說明，正確的研究程序包含以下步驟[cite: 2]：
1. **研究題目界定**：找到好的研究主題，以及如何吸引讀者讀下去的起手式（研究背景、動機與目的）[cite: 2]。
2. **文獻探討與觀念架構**：建立堅實的理論基礎，並找出探討的主要變數與研究假設[cite: 2]。
3. **研究設計**：規劃具體可行的步驟，包含變數的操作化定義、變數衡量、工具發展及樣本選擇[cite: 2, 8]。
4. **資料蒐集與分析**：
   - **質化研究**：透過檔案資料 (archival sources)、觀察、訪談與田野調查進行探索與解釋，資料分析多為歸類與摘要等[cite: 8]。
   - **量化研究**：透過問卷或數據機率性取樣，進行橫斷面或縱斷面的統計與數學分析[cite: 8]。
5. **研究結果與討論**：呈現具有信服力的結果，並探討其意涵與貢獻[cite: 2]。
6. **結論與限制**：探討研究限制、未來建議與結論[cite: 2]。

## 三、 課程要求與評分標準
依照「研究方法_課程大綱.pdf」與課堂說明之規範[cite: 1, 2]：
- **[分組](https://docs.google.com/spreadsheets/d/1HmW9h9UyK23I34VN96FcdxcPagFdxmsUfTmcybWI_MY/edit?gid=0#gid=0)報告與Q&A (35%)**：報告組需精讀文章、製作投影片並導讀 20-25 分鐘；非報告組需在上課前一天 (週四) 中午前針對文章上傳提問[cite: 1]。

- **期末報告 (40%)**：期末分組提出研究計畫並進行報告（包含研究動機、目的、方法等）[cite: 1, 2]。
- **提問與課堂討論 (15%)**：每週需閱讀研究文章，並進行提問及課堂討論[cite: 1, 2]。
- **出席率 (10%)**：每次無故缺席扣 3 分，請假超過 3 次後每次扣 3 分；總缺席達 6 次則學期成績以不及格計算[cite: 1, 2]。

## 四、 結合軟體工程管理 (Software Engineering Management) 的觀點
參考您提供的網站內容與專案管理文獻精神，學術研究的過程其實與「軟體工程管理」的方法論有許多共通之處：
1. **敏捷與迭代開發 (Agile/Scrum)**：課堂中強調「計畫書的發展是逐步累積的，不要想一步完成，需多次討論與修改」[cite: 9]。這與軟體敏捷開發強調的「短週期迭代 (Sprint)、持續溝通與修正」以因應變化[cite: 11] 的精神完全一致。
2. **系統分析與問題定義**：軟體專案在初期講求精確的系統需求與成本效益評估[cite: 11]；在研究程序中，這對應到「研究題目界定」與釐清「核心探討變數」[cite: 2]，都是確保後續專案不歪樓的關鍵步驟。
3. **專案時程與產出控管**：進行研究計畫如同推動一項軟體專案，兩者都需要嚴謹的進度控管機制與階段性交付[cite: 9, 11]。透過有紀律的規劃，才能兼顧時間與預算，如期交付具有價值的研究成果或系統服務[cite: 11]。
